Static UI library · HTML / CSS / SVG

Prototype UI Kit

A small, reusable starting point for interface prototypes. This showcase links to the available component examples.

Components

Reusable pieces with standalone examples.

  • Button — responsive variants, sizes, density, disabled, icon placement, and full width.
  • Checkbox — native checkbox with label, description, and checked/disabled states.
  • Check — reusable checkbox indicator.
  • Icon — inline SVG artwork with configurable size.

Project principles

Plain files, no build step, no runtime loader. Copy only the files a component needs, and make any shared token requirements explicit.
